Agilitas Sports Private Limited is a Bengaluru-based sports and athleisure company founded in
February 2023 by former Puma India leaders Abhishek Ganguly, Atul Bajaj and Amit Prabhu — a
vertically integrated manufacture / brand / retail ecosystem, not a software business. It acquired
Mochiko Shoes, holds the exclusive India licence for Lotto, and runs the one8 brand with Virat Kohli.

It publishes no developer program and no OpenAPI. What it does serve, on its own domain, is a real
agent-facing commerce surface generated by its Shopify platform:

- `https://agilitas.com/llms.txt` and `/agents.md` — published agent instructions
- `https://agilitas.com/.well-known/ucp` — Universal Commerce Protocol merchant profile, UCP 2026-08-25
- `https://agilitas.com/api/ucp/mcp` — live unauthenticated MCP server, 13 catalog / cart / checkout / order tools
- `https://agilitas.com/api/mcp` — live unauthenticated storefront MCP server, 1 policy-and-FAQ tool
- `https://agilitas.com/.well-known/openid-configuration`, `/oauth-authorization-server`,
  `/oauth-protected-resource` — Shopify customer-account OAuth 2.0 / OIDC discovery

There is no security.txt, no A2A agent card, no status page, no changelog, no SDK and no CLI.
